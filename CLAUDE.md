# Claude Code — Xenomit

**Read and follow [`AGENTS.md`](./AGENTS.md) in this repository.** The rules there are the shared baseline for orchestration, preserving user work, repo-specific instructions, GitHub workflow, dependency pinning, merge checks, and delegation.

When working inside another Xenomit repository, also read that repository's root `AGENTS.md` and `CLAUDE.md` (synced from this repo). If **`AGENTS.local.md`** or **`CLAUDE.local.md`** exists there, read it as **repository-specific supplementary guidance**. Read any other local contributor docs before making changes.
